## 交接说明

### 更换环境时

1. **整个仓库一起带过去**（包含 `.docs/`）——git 历史就是完整的过程记录。
   - 若新环境是 **`git clone` 得到的**：本地提交必须先 `git push` 到远端，
     否则新环境拿不到（远端：`https://github.com/Aa-arun/iagd`）。
   - 若直接**复制整个目录**：不需要 push。
2. 新对话开场只需说：**"读 `AGENT.md` 和 `.docs/00-当前状态.md`"**。
3. **不要依赖对话里的口头摘要**：会失真，且会与文档冲突。

### 每次会话结束前

1. 让 AI 更新本文件的「现在在哪 / 下一步 / 最近完成」。
2. 把新产生的决定归档到 `.docs/05-实施计划.md` 的决策记录。
3. `git commit`——**提交信息本身就是"过程"的载体**，不必写进文档。

### 如果发现"只有聊天记录里才有"的信息

说明文档有缺口。**把它补进文档**，而不是留着靠摘要传递。
