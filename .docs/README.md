## 技术路线（已定）

**后端服务化 + 系统浏览器访问 + 前端用 React 重做**，通信 **REST + WebSocket**。
最终去掉 WinForms 与 WebView2，只保留托盘图标。

```
改造前                              改造后
IAGrim.exe                          IAGrim.exe（后台服务 + 托盘）
 ├ WinForms 主窗口                    ├ HTTP 服务（REST）
 └ WebView2 → 网页                    ├ WebSocket（推送）
                                      └ 托盘图标
                                     系统浏览器 → 127.0.0.1:PORT
```

> 进度与下一步见 [`00-当前状态.md`](./00-当前状态.md)。

## 写作约定

### 命名
`.docs/NN-主题.md`，两位数字前缀决定阅读顺序。内容用中文。

### 三条硬规矩

1. **区分"事实"与"推测"。** 未验证的推测必须标注：
   > ⚠️ 待确认：……
   不要把自己的猜测写成事实——下一次对话的你会当真。
2. **引用代码要给出相对仓库根的路径**，例如 `WebUI/src/containers/ItemContainer.css`。
3. **记录"为什么不做"**，而不只是"做了什么"。放弃的方案往往比选中的更有信息量。

### 不要记录什么

- ❌ **不要在每个文档末尾记"变更记录"。** 那是历史痕迹，会打断阅读。
  真正重要的决策集中记在 `05-实施计划.md` 的决策记录里。
- ❌ **不要写"原本打算 X，后来改成 Y"的叙述。** 直接写最终结论 + 一句理由。
  过程属于 git 提交信息，不属于设计文档。
